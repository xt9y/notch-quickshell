# Wallpaper

Drop one wallpaper image into this directory to have `config-update` configure and start hyprpaper automatically.

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.

The filename does not matter. If multiple supported images exist, the first one in sorted filename order is used.

If this directory contains no supported image, the repo does not enable hyprpaper and leaves any existing non-repo wallpaper configuration alone.
